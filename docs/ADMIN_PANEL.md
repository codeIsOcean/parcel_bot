# Админ-панель (Mini App)

Экран `/admin` (`webapp/src/views/AdminView.vue`), вход — кнопка «Админ-панель» в своём
профиле или команда `/admin` в боте. Доступ: `ADMIN_IDS` из `.env` (владельцы, снять нельзя)
или флаг `users.is_admin`, назначаемый из панели.

API: `backend/app/routers/admin.py` (`/api/v1/admin/*`), логика — `backend/app/services/admin_service.py`.
Проверка — dependency `get_current_admin` (403 обычному). Фронт узнаёт о правах из `is_admin`
в `/users/me`.

## Разделы

| Раздел | Что показывает | Действия |
|---|---|---|
| Статистика | люди (всего/сегодня/неделя/с телефоном/заблокированы/перевозчики), посылки, рейсы, заявки, жалобы, группы и посты, выручка в ⭐, отзывы | — |
| Пользователи | поиск по id/@username/имени/телефону, фильтры blocked/admins/travelers/reported, карточка с посылками, рейсами, жалобами | блокировать/разблокировать (с пушем), галочка «проверен», назначить/снять админа, изменить баланс ⭐ (проходит через `balance_service`, пуш пользователю) |
| Посылки | фильтр по статусу, поиск | принудительная отмена (закрывает посты в группах) |
| Рейсы | фильтр по статусу, поиск | принудительная отмена (закрывает посты) |
| Группы | реестр подключённых групп | см. `docs/GROUPS.md` |
| Жалобы | открытые/все, автор → цель, причина | reviewed / confirmed, быстрая блокировка цели |
| Платежи | список платежей | — |
| Поддержка | инбокс открытых/архив, переписка | ответ (уходит в бот и в KVD-панель), закрыть |
| Рассылка | аудитория all/senders/travelers/with_phone | отправить (не шлём заблокированным и скрывшим бота) |

Себя и владельцев из `.env` заблокировать нельзя; владельца из `.env` нельзя снять с админа.

## Тесты

`tests/test_admin_api.py` — доступ (401/403/200), поиск и блокировка, роли, баланс,
отмена посылок/рейсов с закрытием постов, жалобы, группы (getChat замокан), рассылка, поддержка.
